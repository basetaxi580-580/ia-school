# Frontend IA School

## Stack
- React 18
- Vite 5
- Nginx para servir producción

## Función
- Listado de estudiantes
- Búsqueda y filtro por estado
- Formulario de alta y edición
- Eliminación
- Resumen básico del dashboard

## Rutas
- `/` redirige al dashboard
- `/inventory` no aplica todavía

## Comandos
```bash
cd frontend
npm install
npm run build
```
